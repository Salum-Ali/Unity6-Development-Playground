# Naming Conventions

## General

- Use PascalCase for folder names and asset names unless
Unity conventions or an external tool suggest otherwise.
- In both the root of the /Assets/ and project root folder, there is a leading unerscore (_) in the folders I created myself. This is to distiguish them from auto-generated folders of the default 3D URP template in Unity as well as any other outside folder structure, unless Unity or external conventions or tools force me to change this system for some [good] reason.

## Assets - will change this title once I figure out a better way of wording it. That said, i ddo like this way of wording it for the time being

Please note that this is an evolving part of this document. Threfore things *can an will* change an grow as needed. For example, I may decide other naming conventions are better / easier / make more sense to me, etc. so I will change them here as needed.
